把日常写成值得读的文章

试排导语

同一篇文章，可以安静，可以清楚，也可以有一点锋芒。这份试稿用相同内容比较九套主题，所有颜色、标题与留白都应帮助阅读。

01先留住一个具体的场景

清晨，街边的小店刚刚开门。桌面还留着一圈杯底的水痕，窗外的脚步声由疏到密。我们先写下看到的东西，再决定它意味着什么。

重要的判断需要被看见，但整页都加粗，读者就失去了方向。这里是一句需要留意的话，而不是另一个抢占注意力的标题。

一段值得留下的文字，往往从一个不急着解释的细节开始。

它让读者看见，也给读者留下自己的理解。

让细节承担一部分叙述

人名、动作、地点与感受可以出现在同一段里。排版应当让它们自然相连，不替原文制造没有出现过的作者、日期或来源。

02再给信息安排清楚的次序
•
一层标题，只回答一个问题。
•
一段文字，尽量沿着同一个意思向前走。
•
必要的补充，放进真正属于它的层级。
•
需要记住的结论，仍然依靠内容成立。
元素用处阅读节奏
标题提供方向适度停顿
引用保留另一种声音慢一点
列表展开步骤和要点清楚向前

代码与正文不同：重复空格、标点和换行本身就是内容。比如 const note = "a b" 不应在复制后悄悄改变。

const note = "a  b"

if (note) {

    return note

03最后，把多余的东西拿走
01
从头读一遍，看标题是否真的对应正文。
02
检查引用、图片说明和参考链接是否完整。
03
在手机宽度下复核，再进入正式发布流程。

试排提醒

这里的表格与文字仅用于主题比较。视觉检查、微信兼容检测和真实公众号粘贴验收是不同的步骤。

最后留下一句平常的话：让读者记住文章，而不是记住排版工具。
