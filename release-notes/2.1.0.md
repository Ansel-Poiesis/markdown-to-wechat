# 2.1.0 · 编辑工作台与 Agent 渲染

发布日期：2026-09-27。

本版重建了排版工作台与九套文章主题，并把渲染能力接入可校验、可追溯的 Agent 任务流程。

## 新功能

- 与声笺一致的灰绿新拟态工作台，支持浅色、深色及窄屏布局。
- 重建秋河、朱简、松烟、月白、青黛、竹青纸本、海棠、薯片纸袋、流金九套主题，统一封面、章节、引用、表格与结尾表达。
- 新增 Agent 控制台与 JSON/CLI 合同，可准备公众号、独立网页及 imagegen 长图任务；导入任务会另建草稿。
- 长图支持纸上编辑部、理性网格、墨与留白三种构图，保留原稿、HTML、提示词、图片及 SHA-256 回执。

## 修复

- 修复代码块、列表、表格、转义和链接等 Markdown 边界问题。
- 加入正文、结构与输出预算，超限时保留原稿并停止输出。
- 修复草稿保存错误提示、连续参数持久化、富文本复制和快速调整窗口引发的 ResizeObserver 错误。
- 收紧 Electron IPC、外部链接、图片上传、反馈回执及 AI 流式响应边界。

## 使用与边界

使用 [在线工作台](https://ansel-poiesis.github.io/markdown-to-wechat/)，或从本 Release 下载 Windows x64 安装包/便携包。校验文件为 `SHA256SUMS.txt`。

Agent 命令见 [接口合同](../AGENT_CONTROL.md)。imagegen 由外部 Agent 调用图像工具；本项目准备和接回任务产物。平台发布由后续已授权流程执行，生成图片中的文字仍需复核。

发布验证结果、构建来源及资产指纹随 Release 的 `manifest-2.1.0.json` 提供。公众号真实后台粘贴验收不等同于自动兼容性检查；本轮不声明完成该人工验收。
